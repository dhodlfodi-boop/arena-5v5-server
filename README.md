
## Q/E 영웅 스킬

VANTA의 Q `SCAN`은 서버가 사용 가능 상태와 생존 여부를 검사한 뒤 12초 쿨타임을 적용합니다. 사용하면 반경 420 게임 단위 안의 적을 서버가 판정하고 3.5초 동안 스캔 이벤트와 탐지 수를 전송합니다. 클라이언트에는 확장되는 3D 스캔 링이 표시됩니다.

E `SMOKE`는 18초 쿨타임이며, 사용 위치에 8초 동안 남는 서버 효과를 생성합니다. 클라이언트에는 반투명 3D 연막 구역이 표시되고, 효과 만료 시 서버 상태에서 제거됩니다.

클라이언트가 쿨타임을 속여도 서버가 `ability_denied`를 반환하며 효과를 생성하지 않습니다. 성공한 사용에는 `ability_cooldown` 메시지가 내려가 HUD에 남은 초가 표시됩니다. 키보드 `Q`/`E`와 모바일·마우스 버튼 모두 같은 서버 메시지를 사용합니다.
